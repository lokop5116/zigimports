## Notes for the reviewer

* The package calls shared libraries compiled with the 'Zig' compiler
  (https://ziglang.org), which is listed in SystemRequirements. The compiler
  is only needed for `zig_call()` and for building user libraries; the package
  itself installs without it. All examples and tests that need Zig are
  guarded and skipped when it is not available, so they do not run on CRAN.
* When compiling, all 'Zig' cache and build files are written to temporary
  directories, never to the user's home directory.
* `src/dispatch.c` is generated by `data-raw/gen_dispatch.py`
  (not part of the built package).
